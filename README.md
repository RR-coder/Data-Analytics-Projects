## Project 4: Financial Performance Analytics

### Objective
Analyze revenue, profit, customer segments, product performance, and regional business performance.

### Skills Used
- SQL
- Python
- Tableau
- Financial Analytics
- KPI Analysis
- Business Intelligence

### Key Insights
- Revenue: $2.3M
- Profit: $286K
- Profit Margin: 12.47%
